ハッカソンで使いやすい理由

Cloudflare に出す前のコードを、そのまま自分の缶に詰めて配る。Kanzume がやるのはそれだけです。

  • 無料のサーバー 1 台で動く512MB RAM / 0.1 CPU 程度の無料プランを想定して、軽さを最優先に作っています。データは R2 などに暗号化してバックアップでき、空の状態で起動しても自動で戻ります。
  • wrangler の書き方のままfetch ハンドラ・KV・R2・静的アセットを wrangler の設定どおりに使えます。あとから wrangler deploy でほかへ移すときも、コードはそのままです。
  • 5 つの方法でデプロイファイルのドラッグ＆ドロップ、サンプル、GitHub の公開リポジトリ、GitHub Actions、Kanzume 上の Git リポジトリへの push から選べます。ほかのサービスのアカウントは要りません。
  • チームで見られる管理画面パスキーでログインし、デプロイ履歴・コード・リクエストのログ・KV と R2 の中身を確認できます。チームには招待リンクで、そのサイトだけを任せられます。

対応している機能

fetch ハンドラ○ES Modules 形式。オブジェクトと WorkerEntrypoint の両方
KV○get / put / delete / list、metadata、expirationTtl
R2○get / put / head / delete / list、range、httpMetadata
Static Assets○html_handling / not_found_handling / run_worker_first
nodejs_compat△buffer・crypto・stream・util など。fs や net は使えない
D1・Durable Objects・Cron・Queues×今は対応していません

サイト

サイトを作る

管理画面のサイトの切り替えから「＋ サイトを追加」を選び、サイト名を決めます。サイト名がそのままサブドメインになります（blog → blog.example.com）。英小文字・数字・ハイフンで 63 文字までです。

作っただけのサイトは「未デプロイ」で、まだ配信しません。「デプロイ」タブで デプロイの方法 を選びます。環境変数・シークレット・メンバーは、デプロイの前でも設定できます。

サブドメインを変える

「サイト設定 > サブドメイン」で変えられます。変えると、前のサブドメインでは配信しなくなります。サイトの ID（作ったときの名前）は変わらず、git push や GitHub Actions では引き続き ID を wrangler の name に使います。

ルートドメインのサイト

「管理者設定 > ルートドメインのサイト」で、ルートドメイン（example.com）で配信するサイトを 1 つ選べます。最初に管理者がデプロイしたサイトは、自動でルートになります。

ルートのサイトは管理画面と同じオリジンで動きます。そのサイトにデプロイできる人は、管理者と同等になる点に注意してください。

環境変数とシークレット

「サイト設定」の「環境変数」と「シークレット」で、Worker の env に入る値を決めます（nodejs_compat なら process.env にも入ります）。

  • wrangler の設定の vars と同じ名前なら、管理画面の値が優先されます。
  • 保存すると、再デプロイしなくても次のリクエストから反映されます。
  • シークレットは保存したあと値を表示しません。値の変更と削除だけができます。
  • 名前は英数字と _ で、数字以外から始めます。値は 1 つ 5KB まで、全体で 64KB までです。

サイトを削除する

「サイト設定 > サイトの削除」で、公開を止め、KV / R2 のデータ・デプロイ履歴・ログと、同じ名前のリポジトリをすべて削除します。

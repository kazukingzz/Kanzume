データベースとストレージ

KV と R2 のデータはサイトごとに分かれます（同じ binding 名でも、別のサイトのデータとは混ざりません）。管理画面では、デプロイ前のサイトでもタブが表示され、データがなければ wrangler の設定の例が出ます。

データベース（KV）

  • 名前空間（binding）ごとにキーを一覧し、キーの先頭で絞り込めます。
  • キーを開くと、値（JSON は整形して表示）・metadata・有効期限が見られます。
  • キーの追加・値の編集・削除ができます。値は文字列で保存し、有効期限（60 秒以上）も付けられます。
  • バイナリの値は表示・編集できません。大きな値は先頭の 256 KiB だけを表示します。

ストレージ（R2）

  • バケットごとに、/ 区切りのキーをフォルダとしてたどれます。
  • オブジェクトを開くと、テキストならプレビューが出て、サイズ・Content-Type・アップロード日時・ETag が見られます。
  • ダウンロード・削除と、今のフォルダへのアップロード（複数ファイル可。KANZUME_MAX_UPLOAD_MB まで）ができます。
  • ダウンロードは常にファイルとして保存されます（管理画面のオリジンで開かれないようにするため）。

wrangler の設定から外したあともデータが残っている名前空間・バケットは「設定にない」と表示されます。

Kanzume ドキュメント

Kanzume は、Cloudflare Workers 向けに書いたコード（export default { fetch } と wrangler.jsonc）を、書き換えずに自分のサーバー 1 台で動かせるセルフホスト環境です。ハッカソンのように、短い期間に複数のチームがそれぞれのサイトを公開する場面を想定しています。

できること

  • サイトをいくつでも置き、<サイト名>.example.com のサブドメインで配信する（1 つはルートドメインでも配信できる）
  • Worker・静的アセット・KV・R2・環境変数・シークレットを wrangler の設定どおりに使う
  • 4 つの方法でデプロイする（サンプル・GitHub の公開リポジトリ・GitHub Actions・Kanzume 上の Git リポジトリへの push）
  • パスキーでログインする管理画面で、デプロイ履歴・コード・リクエストのログ・KV / R2 の中身を見る
  • サイトごとにメンバーを招待し、そのサイトだけを任せる
  • データを S3 互換ストレージ（Cloudflare R2 など）に暗号化してバックアップし、空の状態で起動したら自動で復元する

できないこと・注意

  • Cron Triggers・D1・Durable Objects・Queues・WebSocket などには対応していません（対応している機能）。
  • Worker は node:vm で Kanzume と同じプロセスの中で動きます。セキュリティ境界ではないので、デプロイできる人は信頼できる相手に限ってください。
  • npm パッケージを使うコードは、GitHub Actions でバンドルしてからデプロイします。

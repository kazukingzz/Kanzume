可観測性とリソース

可観測性

サイトの「可観測性」タブで、そのサイトへのリクエストを見られます。

  • 概要: 1 時間・24 時間・3 日のリクエスト数・エラー率・実行時間（p50 / p95 / p99）と、そのグラフ
  • イベント: リクエストごとの時刻・ステータス・メソッド・パス・実行時間。結果（成功・エラー）と種類（Worker・アセット）で絞り込み、パスやログで検索できる
  • イベントを開くと、Worker の console.log と例外が見られる
  • 「ライブ」で新しいリクエストを流しながら見られる

ログは KANZUME_LOG_RETENTION_HOURS（既定 72 時間）だけ残します。

リソース

管理者は「リソース」タブで、コンテナの CPU とメモリの使用量・上限（cgroup の値）と、動いている Worker の子プロセス（サイト・メモリ）を見られます。
